## 🏛️ Produtos

| Produto | O que faz |
|---|---|
| **00.Holtz Advogados** | Painel de gestão do escritório: caixa de entrada unificada, agenda de consultas, funil de clientes e triagem por IA. |
| **TRIADE Sign** | Assinatura eletrônica de documentos, com convite por e-mail ou WhatsApp e validação por QR Code. |
| **TRIADE IA Solutions** | Automação para escritórios de advocacia: atendimento no WhatsApp, prazos, honorários e geração de documentos. |

---

## 🧰 Stack

**Front-end:** React · TypeScript · Tailwind CSS · shadcn/ui · criado no Lovable
**Back-end e dados:** Supabase (Auth, PostgreSQL, Storage, Edge Functions)
**Automação:** n8n · Make · scripts em Python
**Comunicação:** WhatsApp (API oficial e Evolution API) · e-mail transacional
**Marketing e dados:** Google Ads · Google Analytics · Meta Ads

## ⚙️ Como trabalhamos

- 🔄 Código sincronizado com o GitHub pela integração do **Lovable**, no branch `main`.
